# Arah tampilan

Identitas project awal week5_offline_notes dipertahankan: daftar teks Material, aksen indigo dan tipografi Android yang mudah dibaca. Design Read: catatan praktikum untuk mahasiswa, daftar Material sederhana; ENERGY 1 / RHYTHM 1 / MOTION 1.

Daftar memperjelas urutan pembaruan; divider dan spasi memisahkan catatan. Dirty badge adalah status fungsional. Ikon tambah/edit/hapus/pengaturan/artikel/sync menunjukkan tindakan sebenarnya. Terang menjadi default, gelap mengikuti preferensi. Dialog bisa discroll saat keyboard muncul. Tidak ada logo/ilustrasi baru, statistik rekaan atau navigasi tanpa tujuan.

Hasil: enam screenshot diperiksa; tema terang/gelap, badge, daftar dan settings tidak menunjukkan clipping. Test widget 320 px memeriksa judul panjang di kedua tema dan kontras badge >=4.5:1. Tab/Enter memvalidasi form, Escape menutup dialog. Integrasi emulator menjalankan kontrol CRUD, navigation, preferensi, cache serta sync. [Delivery gate PASS](antislop-gate.md) mencatat bukti per aturan.
