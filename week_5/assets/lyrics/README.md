# Lirik Peradaban

Simpan teks lirik yang Anda sediakan sebagai `peradaban.txt` (UTF-8) dalam folder ini. Baris kosong memisahkan bait. Aplikasi akan membaca file tersebut pada halaman Peradaban.

Audio penuh memakai `assets/audio/peradaban.mp3`. Jalankan ulang aplikasi setelah menambahkan aset.

Tanpa file lirik, aplikasi menampilkan “Lirik belum tersedia”. Teks lama yang tidak sesuai telah dihapus.
